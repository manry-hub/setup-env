build: Perubahan yang memengaruhi sistem build atau external dependencies (contoh scope: gulp, broccoli, npm)

ci: Perubahan pada file dan skrip konfigurasi CI (contoh scope: Travis, Circle, BrowserStack, SauceLabs)

chore: Perubahan yang tidak mengubah source code atau test, misal perubahan pada proses build, auxiliary tools, libraries

docs: Untuk perubahan dokumentasi

feat: Untuk fitur baru

fix: Untuk Bug fix

perf: Perubahan kode yang meningkatkan performa

refactor: Perubahan kode yang tidak memperbaiki bug atau menambahkan fitur

revert: Mengembalikan perubahan yang lalu

style: Perubahan yang tidak memberikan efek pada kode (misal white-space, formatting, missing semi-colons, etc)

test: Menambah test atau mengubah test
